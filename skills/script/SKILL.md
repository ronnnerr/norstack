# script

One idea. One hook. Receipts on screen. If the first line needs a setup, it is not a hook.

the channel → also load `channel`. Titles/CTAs after the script → `copy`. Animated version → `explainer`. Thumbnail line → `thumb`.

## Output (fill this, in this order)

Write the file to the video folder as `script.md`. Use `~/norstack/skills/script/TEMPLATE.md`.

Required slots: Title · HookA/B/C · Promise · Beats · Payoff · Outro · Sources · Thumb line · Description. Missing a slot means the script is not done.

## Hook

Write 3 hooks. Pick one. A hook is a complete thought a stranger gets with no preamble.

| Family | Shape | Example |
|---|---|---|
| Named mechanism | You do X. It has a name. | "You re-read the text. That is not love. That is variable reward." |
| Lived scene | 8 words they have already done | "You already know what the text says." |
| Receipt | Named paper, real number | "In 2014 people shocked themselves rather than sit alone with their thoughts." |
| Myth flip | Common belief, then the kill | "Willpower is not a muscle. That finding did not replicate." |
| Status | Earned, specific | "If you explain yourself twice, you already lost." |

Spoken hook ≤ 3 seconds or a 1-second picture plus the line by second 8.

Dead on arrival: "Have you ever", "In this video", "Let's dive in", "What if I told you", "Studies show" with no study, "your mental health journey", fake countdown urgency.

## Beats

Each beat is **Claim → Receipt → Turn**.

- Claim: one sentence
- Receipt: author, year, journal or book, one-line finding. Or a concrete observable the viewer can check.
- Turn: what that finding changes about the viewer's next hour

No receipt? Cut the beat. Do not pad with "researchers believe."

Short (35–55s): 1 hook + 2 beats + payoff. ~90–130 spoken words.
Long (8–14 min): hook + 5–8 beats + payoff. ~1,200–1,800 words.
Explainer: same words, but every receipt becomes an on-screen card. `explainer` owns the cards.

## Voice

Precise. Slightly dry. Curious. Short sentences. No em dashes. No therapist. No Headspace.

Allowed: the name of the effect, the ugly detail, the limit of the finding.
Forbidden: diagnose the viewer, treatment advice, invented citations, "it's okay to feel."

If a beat touches clinical territory, the Outro includes a one-line not-advice card. `channel` owns that rule.

## Titles

After the script, 5 titles. Specific > dramatic. Promise the turn, not the topic.

Weak: "The Psychology of Overthinking"
Better: "You Are Not Overthinking. You Are Bargaining."

## Verify

Read the hook out loud. If you need a clause of context, rewrite it.
Every number in the script appears in Sources with a URL or DOI.
Do not ship a script whose Sources were recalled from memory. Search first.
