# hook

Footage in → first 3 seconds out. Words on a blank page → `script`.

1. `video` `see` the source. Read the first 4 seconds of frames.
2. The cut is a complete thought a stranger understands with no setup. If the take does not contain one, stop and write it in `script` instead of manufacturing a fake open.
3. Cut on a word boundary if there is a transcript. Never mid-word.
4. If this will be a short, run `portrait` on the hook window, not the whole file.

Do not diagnose. Do not invent studies.
