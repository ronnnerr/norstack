# taste

Identity overlay. Craft is `ui`. Do not install UI UX Pro Max. Do not follow gstack DESIGN.md.

Load `ui` after this page. Impeccable at `~/.agents/skills/impeccable/SKILL.md` is an engine if `ui` is not enough.

## Register

- **Product / tool UI** (the desktop app, pred, the video product app, dashboards): operator register. Restraint. Dark because the scene is a desk at night, not because "tools are dark." Tinted neutrals + one earned accent. Keyboard density. No cards-in-cards. No hero metrics. No gradient text. No glassmorphism.
- **Brand / marketing** (landings, client portfolios, ads): design IS the product. Write a physical scene sentence before picking a palette. Reject the first category reflex (fintech navy-gold, crypto neon, generic SaaS cream).

## Project-specific anti-references

- gstack / Garry default voice and purple-orange launch-video chrome
- Notion, wellness apps, emoji confetti, therapy-speak
- Generic SaaS cream, identical icon-card grids
- the desktop app look copied onto a client or onto the agency

## the desktop app (when that is the venture)

Three words: precise, private, unhurried-under-pressure. Lineage: Arc, Raycast, Linear, Superhuman. Glow is earned. One dark theme.

## Process

1. Load PRODUCT.md / DESIGN.md via impeccable's loader if they exist. Don't invent a PRODUCT.md from the prompt alone.
2. If PRODUCT.md is missing and this is a real product repo, run impeccable `teach` before crafting.
3. Shape before craft when the surface is new.
4. After visual changes, `browse` the running UI or open the HTML. Taste without eyes is guesswork.
5. Run the AI slop test from impeccable before showing the user.
