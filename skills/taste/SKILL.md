# taste


Load `ui` after this page for the craft layer.

## Register

- **Product and tool UI** (apps, dashboards, internal tools): operator register. Restraint. Dark because the scene is a desk at night, not because "tools are dark." Tinted neutrals + one earned accent. Keyboard density. No cards-in-cards. No hero metrics. No gradient text. No glassmorphism.
- **Brand / marketing** (landings, client portfolios, ads): design IS the product. Write a physical scene sentence before picking a palette. Reject the first category reflex (fintech navy-gold, crypto neon, generic SaaS cream).

## Project-specific anti-references

- Notion, wellness apps, emoji confetti, therapy-speak
- Generic SaaS cream, identical icon-card grids
- One project's look copied onto a client or onto another project

## Operator tools

Three words: precise, private, unhurried-under-pressure. Lineage: Arc, Raycast, Linear, Superhuman. Glow is earned. One dark theme.

## Process

1. Load the repo's existing product or design document if there is one. Do not invent one from the prompt alone.
2. If no design document exists and this is a real product repo, write one before crafting.
3. Shape before craft when the surface is new.
4. After visual changes, `browse` the running UI or open the HTML. Taste without eyes is guesswork.
5. Run the AI slop test below before showing the user.

## Do not

- Restate `ui` here. One home for craft: `ui`.
- Use em dashes in UI copy.
- Ship a design you have not seen.
