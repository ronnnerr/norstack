# post

1. Detect the project (`profile`). Identify the project.
2. `portrait` the source. Logo only if that venture has a kit in `~/norstack/brands/`.
3. `thumb` three options.
4. Write a caption: one hook line, no hashtag soup, no em dashes.
5. Hand back: mp4 path, thumb path, caption text.

Look at the portrait frames before calling it done. If the pan is jumpy, re-run portrait. The tracker is every-frame and damped — a jumpy file is a bug.
