# profile

Template. Copy to `profile.md` and replace everything below with your own projects.
`profile.md` is gitignored.

## Operator

How you want agents to talk to you. Two or three lines.

Example: direct, builder to builder. Name the file, the command, the visible result.
Short paragraphs. End on what happened and what is next. Do not ask "should I
continue," build the first complete cut and report.

## Projects

| Project | What it is | Where it lives | Runs at |
|---|---|---|---|
| example-app | Local-first desktop tool | `~/projects/example-app` | http://localhost:1420 |
| example-site | Marketing site | `~/projects/example-site` | https://example.com |
| example-channel | Educational video channel | `~/Media/norstack/channel` | n/a |

Add a row per project. Delete the examples.

## Brand per project

### example-app

- Palette: one background, one foreground, one accent. Write the hex codes.
- Type: family, weights, and where each is used.
- Register: how it speaks. Precise? Playful? Clinical?
- Anti-references: what it must never look like.

### example-site

Same four lines. Repeat per project.

## Never blend

List pairs that must stay separate. Two products with similar names, a client brand
against your own, a personal channel against agency work.

Example: example-app and example-site are different products with different palettes.
Do not carry one's chrome onto the other.

## Forbidden across everything

Claims you will not make without a source. Visual patterns you have banned. House
style rules.

Example: no invented metrics, no gradient text, no glassmorphism as decoration, no
em dashes, sentence case headings.
