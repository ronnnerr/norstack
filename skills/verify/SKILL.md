# verify

- Code: run the test or the command. Paste the output.
- Site: `browse` it. Screenshot + console errors.
- Video: extract 4 frames of the **output** and Read them. Face-follow must not hop.
- Trading: never verify a fill you did not read from disk or the API.

No evidence → not done.
